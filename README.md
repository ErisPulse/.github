### English

ErisPulse is an **event-driven, multi-platform chatbot framework**. Write handlers once and run them across **15+ platforms** — QQ, Telegram, Kook, Yunhu, WeChat Official Account, Matrix, Discord, Email, OneBot11/12 and more.

Hot-reload, a visual Dashboard, Docker images, and a plug-and-play module marketplace included.

</td>
